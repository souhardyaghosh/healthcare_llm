# Healthcare Appointment & Follow-up Manager

## Project Overview
The Healthcare Appointment & Follow-up Manager is an integrated platform designed to manage patient appointments, doctor availability, automated follow-up communications, and scheduling logic.

## Current Module
- **Module**: `M01 — Project Foundation`
- **Scope**: Initializing root repository structure, base configuration, and documentation logging guidelines.

## Architecture Overview
- **Frontend**: React, Vite, JavaScript, React Router
- **Backend**: Node.js, Express, JavaScript, dotenv, cors
- **Database (Planned)**: PostgreSQL, Prisma

## Current Scope & Implementation Note
> **Note**: Future modules (Database schema, authentication, patient/doctor management, appointments, AI features, email notifications, calendar integration, deployment configurations) are not yet implemented in M01.
